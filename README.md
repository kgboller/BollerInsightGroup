# Boller Insight Group

Public website for [Boller Insight Group](mailto:kevin@bollerinsightgroup.com) — fractional data and AI analytics led by Kevin Boller.

This is a static one-page site. There is no build step.

## Local preview

Open `index.html` in a browser, or from this folder:

```bash
npx serve .
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. In Vercel, **Add New Project** and import the repo.
3. Framework Preset: **Other**. Leave Build Command, Output Directory, and Install Command empty.
4. Deploy. Then add the custom domain `bollerinsightgroup.com` in the Vercel project settings.

Contact CTAs use `mailto:kevin@bollerinsightgroup.com` — no environment variables are required.
